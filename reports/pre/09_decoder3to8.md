# 실험 전 레포트: 3:8 디코더

작성일 2026-09-19.

## 목적과 예상값

세 1비트 입력 `a,b,c`가 결합된 3비트 2진수 `{a,b,c}`를 8비트 출력 버스 `o[7:0]` 중 단 하나의 비트만 활성화되는 원-핫(One-hot) 신호로 변환합니다. top은 `decoder3x8`입니다. 논리 시프트 연산 `assign o = 8'b00000001 << {a,b,c};`를 적용하여 000부터 111까지 입력이 증가함에 따라 1이 최하위 비트($o[0]$)에서 최상위 비트($o[7]$)로 순차 이동합니다.

| a | b | c | o[7:0] (2진) | o[7:0] (16진) | 활성 비트 |
|---:|---:|---:|---|---|---|
| 0 | 0 | 0 | 00000001 | 8'h01 | o[0] |
| 0 | 0 | 1 | 00000010 | 8'h02 | o[1] |
| 0 | 1 | 1 | 00001000 | 8'h08 | o[3] |
| 1 | 0 | 0 | 00010000 | 8'h10 | o[4] |
| 1 | 1 | 1 | 10000000 | 8'h80 | o[7] |

## 환경과 입력 파일

Windows, Git 2.55.0, VS Code 1.136.1, XSim 2026.1을 사용했습니다. 공개 템플릿의 커밋 `740aef5`를 공백이 있는 별도 폴더에 새로 clone했습니다. `LAB1.code-workspace`는 `vivado_2026_1/09_decoder3to8`를 PROJECT, `common`을 COMMON으로 연결합니다.

[RTL](../../src/decoder3x8.v), [TB](../../sim/tb_decoder3x8.sv), [XDC](../../constraints/decoder3x8.xdc)를 사용했습니다. TB top은 `tb_decoder3x8`이며 루프 변수 n을 0부터 7까지 10ns 간격으로 인가하여 8가지 전수 조합을 검사합니다. 정수형 시프트 기대 모델(`1 << n`)과 실제 출력을 비교하여 불일치 시 `$fatal`을 호출하고, 8건 완료 시 PASS 출력 후 80ns에 종료합니다.

## 실행과 관찰

VS Code 새 창에서 workspace를 열고 slang-server와 VaporView를 활성화했습니다. 저장 후 Terminal → Run Task...의 Check tools, Simulate를 실행하고 Open waveform으로 VCD를 열었습니다[cite: 8]. `a,b,c,o`를 추가하고 Zoom to Fit와 ns 단위를 선택했습니다.

실제 [VS Code 작업 실행 로그](../../evidence/09/vscode/simulation.txt)에서 `LAB1_PASS decoder3x8 cases=8`과 80ns 종료를 확인했습니다.

| 구간(ns) | a,b,c | o[7:0] (hex) | 해석 |
|---|---|---|---|
| 0–10 | 000 | 01 | 최하위 비트 o[0] 활성화 |
| 10–20 | 001 | 02 | o[1] 활성화 |
| 30–40 | 011 | 08 | o[3] 활성화 |
| 70–80 | 111 | 80 | 최상위 비트 o[7] 활성화 |

전환 순간 대신 구간 중간에서 커서를 읽었습니다. 파형만 눈으로 맞아 보이는 것에 더해 자동 비교 8건과 정상 종료를 함께 확인했습니다.

## 보드 실험 계획

DIP1~3({a,b,c}), LED1~8(o[7:0]), LVCMOS33입니다. Vivado에서 같은 TB를 실행한 다음 bit를 생성하고 보드에 다운로드합니다. 스위치를 000부터 111까지 변경하면서 LED1(o[0])부터 LED8(o[7])까지 정확히 한 개씩만 순차 점등되는 원-핫 디코딩 현상을 사진·영상에 담을 계획입니다.
